TikTok Checker
1. Install Node.js 18+ (nodejs.org)
2. Buka terminal di folder ini, jalankan: node server.js
3. Buka http://localhost:3000
Online 24 jam: upload folder ini ke Render, Railway, Fly.io, atau VPS (start command: node server.js).

Deploy ke Vercel: jalankan "npx vercel" di folder ini. Folder public/ jadi situs, api/tiktok.js jadi fungsi server.
